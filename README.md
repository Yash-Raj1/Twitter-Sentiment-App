# Twitter Sentiment Analysis App

An interactive web app built with **Streamlit** and **Logistic Regression** that predicts whether a tweet is **Positive** or **Negative**.

## Features
- Real-time tweet sentiment analysis
- Confidence score display
- Batch analysis via CSV upload
- Clean and interactive dashboard

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy

## Run Locally
1. Clone this repository
2. Create and activate virtual environment
3. Install dependencies:(pip install -r requirements.txt)
